# Editing Templates

Built-in editor with syntax highlighting and an AI assistant.

---

## How to Open

1. Admin → **Templates**
2. Select a template from the list
3. Edit the code

---

## AI Assistant

Click the **«AI»** button in the editor. Describe what you need:

> "Make product cards from the products table: photo, name, price, a 'Buy' button"

AI generates the code. Click **«Insert into Editor»**.

---

## Creating a New Template

1. Templates → **«Create Template»**
2. Enter a name: `catalog.html.twig`
3. Write the code
4. Save

---

## Hotkeys

| Keys | Action |
|------|--------|
| `Ctrl+S` | Save |
| `Ctrl+F` | Search |
| `Ctrl+/` | Comment line |

---

## After Saving

Changes apply immediately. If you don't see them — clear the cache: Admin → Cache → Clear.
