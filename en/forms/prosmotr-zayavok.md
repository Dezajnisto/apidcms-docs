# 📋 Viewing Submissions

All submitted forms are saved in tables. Viewing is done through the admin panel.

---

## Where to View

1. Admin panel → Tables → select the table (e.g., `contacts`)
2. All submissions are displayed as table rows
3. Click on a row — full view

---

## Submission Statuses

Add a `status` column to the form table:

- `new` — new
- `read` — viewed
- `replied` — replied

Change the status directly in the table.

---

## Admin Notifications

The **Notifications** section (bell icon) shows a summary of new submissions.

---

## Export

On the table page — **"Export CSV"** button. Download all submissions for processing in Excel.
