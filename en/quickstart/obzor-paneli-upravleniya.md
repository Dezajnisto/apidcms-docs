# Admin Panel Overview

After logging in, you see the dashboard. Here are the main sections:

---

## Dashboard (Home)

Tables are grouped into three categories:

### System Tables
Core CMS tables:
- **pages** — site pages (types: page, landing, blog, catalog, form, ai)
- **navigation** — menu structure
- **system_settings** — key-value site configuration
- **forms** — form configurations

### Plugin Tables
Tables created by installed plugins (e.g., account, cart).

### User Tables
Tables you create for your content (e.g., services, portfolio, news).

---

## Sidebar Navigation

- **Home** — dashboard with quick links
- **Tables** — all database tables with grouping
- **Templates** — Twig template editor
- **CSS Styles** — CSS editor with CodeMirror
- **Files** — file manager
- **Forms** — form builder
- **Notifications** — form submissions
- **Plugins** — plugin list and settings
- **Statistics** — visit statistics
- **Clear Cache** — cache management
- **Settings** — site configuration

---

## Top Bar

- **Sidebar toggle** (hamburger menu) — collapse/expand sidebar
- **Page title** — current section name
- **Help button** — context-sensitive documentation panel
- **Files button** — quick access to file manager
- **View Site** — opens your site in a new tab
- **AI Assistant** (floating button, bottom-right) — AI-powered help

---

## Quick Actions on Dashboard

- **Create Table** — opens the table creation dialog
- **Manage Tables** — goes to the full table list
- Each table card shows row count and provides quick links
