# 🚀 Установка и требования

CMS работает на обычном хостинге с PHP. База данных не нужна — используется файл SQLite.

---

## Системные требования

| Что нужно | Минимум |
|-----------|---------|
| **PHP** | версия 8.1 или выше |
| **Расширения PHP** | `sqlite3`, `curl`, `mbstring`, `json`, `gd`, `openssl`, `fileinfo`, `zip`, `xml` |
| **Composer** | менеджер зависимостей PHP |
| **Диск** | около 10 МБ |

> Установщик сам проверит всё необходимое перед началом.

---

## Установка

### 1. Создайте сайт в панели хостинга

Создайте сайт для вашего домена. Хостинг сам создаст папку `www/` и настроит PHP.

### 2. Загрузите CMS

Зайдите в терминал. Замените `мой-сайт.ru` на папку вашего проекта:

```bash
cd ~/мой-сайт.ru
```

Дальше все команды копируются без изменений:

```bash
git clone https://github.com/Dezajnisto/apidcms.git _clone
```

```bash
cp -r _clone/www/* www/ && rm -rf _clone
```

### 3. Запустите установщик

Откройте в браузере `https://ваш-сайт.ru/install.php` и следуйте инструкциям на экране. Установщик проверит требования, установит зависимости и создаст базу данных.

### 4. Откройте сайт

Готово. Админка доступна по адресу `/admin`. Логин и пароль — те, что вы задали при установке.

> ⚠️ После установки удалите установщик:
> ```bash
> rm www/install.php
> ```

## Если нет Git

```bash
cd ~/мой-сайт.ru
wget https://github.com/Dezajnisto/apidcms/archive/refs/heads/main.zip
unzip main.zip && cp -r apidcms-main/www/* www/ && rm -rf apidcms-main main.zip
```

Затем откройте в браузере `https://ваш-сайт.ru/install.php`.

---

## После установки

1. **Смените пароль** (при необходимости). Админка → Настройки.
2. **Настройте AI.** Если нужен — укажите API-ключ в Настройках.
3. **Удалите install.php** (см. выше).

---

## Возможные проблемы

**«Composer not found»** — скачайте Composer вручную:

```bash
cd www
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php composer.phar install --no-dev
```

**Сайт не открывается (502/503)** — убедитесь что сайт создан в панели хостинга и PHP включён.

**«Не найдено расширение pdo_sqlite»** — попросите поддержку хостинга включить `pdo_sqlite` и `sqlite3`.
