# 📊 Обзор панели управления

После входа вы видите главную страницу админки. Вот основные разделы:
![Панель управления apidcms](https://raw.githubusercontent.com/Dezajnisto/apidcms-docs/master/images/admin-dashboard.png)

---

## Главная страница (Дашборд)

Таблицы сгруппированы по трём категориям:

### 🔧 Системные таблицы
Ядро CMS:
- **pages** — страницы сайта
- **forms** — формы обратной связи
- **navigation** — меню и навигация
- **system_settings** — настройки системы
- **entity_relations** — связи между записями
- **visit_stats** — статистика посещений (если включена)

### 🧩 Таблицы плагинов
Таблицы, созданные активированными плагинами (account, cart, subscription и др.). Плагины объявляют свои таблицы через поле `tables` в `plugin.json`.

### 👤 Пользовательские таблицы
Все таблицы, созданные вами через админку.

У каждой таблицы показано количество записей и количество колонок.

## Разделы админки

### 📋 Таблицы
Главный рабочий инструмент. Здесь отображаются все таблицы базы данных.

По клику на таблицу открывается её содержимое с возможностью:
- Поиска и сортировки
- CRUD-операций (создание, чтение, редактирование, удаление)
- **Двойной клик по ячейке** — редактирование через Markdown-редактор
- Изменения структуры таблицы (добавление/удаление колонок)

### 📝 Шаблоны
Раздел для управления Twig-шаблонами. Здесь можно:
- Просматривать список всех шаблонов
- Создавать новые шаблоны
- Редактировать существующие с **подсветкой синтаксиса** (CodeMirror 6, тёмная тема)
- Сохранять изменения по Ctrl+S

### 🧩 Плагины
Управление плагинами:
- Список установленных плагинов
- Активация/деактивация
- Страница плагина: Инфо, Шаблоны, Настройки
- Редактирование шаблонов плагинов с подсветкой синтаксиса

### 📁 Файлы
Файловый менеджер для управления загрузками:
- Загрузка изображений и документов
- Создание папок
- Удаление и переименование файлов

### 🎨 CSS-стили
Редактор глобальных CSS-стилей с подсветкой синтаксиса. Изменения применяются на всём сайте.

### 📊 Статистика
График посещений сайта по дням (если включена статистика).

### 🔔 Уведомления
Заявки с форм (например, «Обратная связь»). Можно:
- Посмотреть новые заявки
- Отметить как прочитанные
- Просмотреть детали заявки

### ⚡ Кэш
Очистка кэша Twig-шаблонов. Используйте, если после изменений на сайте не отображаются правки.

## Быстрая навигация

Слева — боковое меню со всеми разделами. На мобильных устройствах меню открывается по кнопке-гамбургеру.

### 🤖 AI Ассистент
Встроенный AI-помощник. Доступен:
- **Плавающая кнопка** в правом нижнем углу (на всех страницах)
- **Контекстные кнопки** в редакторе шаблонов, таблицах, формах

### ⚙️ Настройки
Управление параметрами сайта:
- Основные настройки (название, описание, favicon)
- AI-настройки (API-ключ, модель, промты)
- Email-настройки (SMTP или API-провайдер)
- Системные настройки
