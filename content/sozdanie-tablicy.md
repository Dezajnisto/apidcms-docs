# 🗄️ Создание таблицы

Таблицы — основа данных в apidcms. Создаются без SQL через админку.

---

## Через админку

1. Админка → Таблицы → **«Создать таблицу»**
2. Укажите название (латиница, нижний регистр, подчёркивания): `products`, `reviews`
3. Добавьте поля:

### Типы полей

| Тип | SQLite | Пример использования |
|-----|--------|---------------------|
| TEXT | TEXT | Заголовки, имена, описания |
| INTEGER | INTEGER | Цены, рейтинги, количества |
| REAL | REAL | Дробные числа |
| DATETIME | DATETIME | Даты |
| BOOLEAN | INTEGER (0/1) | Да/нет |

4. Нажмите «Создать»

---

## Через AI

Кнопка **«AI — Создать таблицу»** на странице создания. Опишите словами:

> «Таблица для каталога товаров: название, описание, цена, фото, категория»

AI вернёт готовую структуру. Нажмите «Применить».

---

## Обязательные поля для динамических страниц

Если таблица будет использоваться с `page_type = 'dynamic'`, добавьте:

| Поле | Зачем |
|------|-------|
| `slug` | TEXT — адрес записи в URL |
| `status` | TEXT DEFAULT 'active' — фильтр published/draft |
| `sort_order` | INTEGER — порядок сортировки |

---

## Редактирование структуры

Чтобы добавить или удалить колонку — используйте [ALTER TABLE](https://www.sqlite.org/lang_altertable.html) через админку (SQL-запрос) или интерфейс «Изменить структуру».
