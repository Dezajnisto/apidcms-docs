# ✏️ CRUD — добавление, редактирование, удаление записей

---

## Добавление записи

1. Админка → Таблицы → выберите таблицу
2. Кнопка **«Добавить запись»**
3. Заполните поля
4. Нажмите «Сохранить»

## Редактирование

1. В таблице нажмите на строку
2. Измените нужные поля
3. Кнопка 💾 (сохранить) в строке

## Удаление

1. В таблице наведите на строку
2. Кнопка 🗑 (корзина)
3. Подтвердите

## Массовые действия

- Выделите несколько строк (чекбоксы слева)
- В верхней панели: «Удалить выбранные»

## Поиск и сортировка

- **Поиск** — поле вверху таблицы, ищет по всем текстовым колонкам
- **Сортировка** — клик по заголовку колонки (▲/▼)

---

## Через AI

Кнопка **«AI — Сгенерировать контент»** на странице таблицы:

> «Сгенерируй 10 постов для блога о веб-разработке»

AI создаст записи. Нажмите «💾 Вставить N записей».

## CSV импорт

На странице таблицы — кнопка **«Импорт CSV»**.

1. Нажмите «Импорт CSV»
2. Выберите CSV-файл на компьютере
3. Система автоматически определит заголовки и сопоставит их с колонками таблицы
4. Проверьте сопоставление и выберите режим импорта
5. Нажмите «Импортировать»

### Режимы импорта

| Режим | Поведение |
|-------|-----------|
| **Добавить все строки** | Каждая строка CSV добавляется как новая запись. При конфликте slug автоматически создаётся уникальный (`slug-1`, `slug-2`...) |
| **Пропустить дубликаты** | Строки, где ключевая колонка совпадает с существующей записью, пропускаются |
| **Обновить существующие** | Совпавшие записи обновляются значениями из CSV. Несовпавшие — добавляются как новые |

### Ключевая колонка

Для режимов «Пропустить дубликаты» и «Обновить существующие» выберите колонку, по которой ищутся совпадения. По умолчанию — `id`.

**Сценарий:** выгрузили таблицу в CSV, поправили данные в Excel, загрузили обратно в режиме «Обновить существующие» — строки обновятся по id.

### Советы

- Первая строка CSV должна содержать названия колонок
- Несовпадающие колонки можно пропустить или сопоставить вручную
- Пустые значения в необязательных колонках станут NULL
- Колонки `id` и `created_at` заполняются автоматически (если не указаны в CSV)

## CSV экспорт

На странице таблицы — кнопка **«Экспорт CSV»**. Скачивает все данные с учётом текущего поиска и сортировки. Файл корректно открывается в Excel (UTF-8 с BOM).
