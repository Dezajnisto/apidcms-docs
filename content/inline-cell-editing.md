## Inline-редактирование ячеек с EasyMDE

Начиная с версии **v1.3.16**, apidcms поддерживает inline-редактирование значений через модальное окно со встроенным **EasyMDE** — полноценным Markdown-редактором.

### Как это работает

- Откройте любую таблицу в админке: `/admin/table/{table_name}`
- Дважды кликните по ячейке — откроется модальное окно с EasyMDE
- Редактируйте содержимое с помощью тулбара или вручную
- Ctrl+Enter или кнопка **Save** — сохранить
- Escape или кнопка **Cancel** — отменить

### Дизайн-изменения

- Вертикальные разделители ячеек
- Подсветка ячейки при наведении (курсор cell)
- Зелёная вспышка при успешном сохранении

### API эндпоинт

```
POST /admin/table/{table}/cell/{id}
Content-Type: application/json

{ "column": "title", "value": "# Новый заголовок" }

// Ответ:
{ "success": true, "value": "# Новый заголовок" }

```

### Безопасность

- Доступ только через админку (ADMIN_ACCESS)
- Валидация имени колонки через структуру таблицы
- PDO prepared statements

### Технические детали

- **EasyMDE 2.21.0** — 320 KB JS + 13 KB CSS (вшито в шаблон)
- Редактор инициализируется при открытии модала, уничтожается при закрытии
- Изменённые файлы ядра: `TableController.php`, `App.php`, `view.html.twig`
- Нет внешних зависимостей — всё локально
