# v2.1.3 — Multi-upload and Batch Delete in File Manager

**Date:** July 30, 2026
**Type:** feature

## What's New

- **Multi-file upload.** The main file manager (`/admin/filemanager`) upload modal is now multi-file capable with drag-and-drop support. Progress bar, file list with sizes, and queue management before submission.
- **Batch delete.** Table view now has checkboxes on every file and folder row. Select multiple items and delete them in one click. Selection counter, confirmation dialog, floating bottom action bar.

## Fixed

- **Twig error in file manager popup.** `/admin/filemanager/popup` was throwing "A mapping key must be followed by a colon" due to invalid triple curly braces `{{{ }}}`. Replaced with `{{ }}`.
- **Popup and main manager synced.** Both now use the same upload, delete, and display mechanics.

### Changed Files

- `core/src/Admin/FileManagerController.php` — `uploadMultiple()`, `deleteMultiple()` methods
- `core/src/Admin/App.php` — `/filemanager/upload-multiple`, `/filemanager/delete-multiple` routes
- `core/views/admin/filemanager/index.html.twig` — multi-file modal, checkboxes, batch delete bar
- `core/views/admin/filemanager/popup.html.twig` — brace fix, checkboxes, batch delete bar
