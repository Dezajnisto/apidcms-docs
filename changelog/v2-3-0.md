# v2.3.0 — robots.txt и sitemap.xml средствами CMS

**Дата:** 11 ноября 2026
**Тип:** feature

## Новое

**Тип страницы `raw`** — отдаёт шаблон темы как есть, без layout сайта, с
заданным `Content-Type`. Раньше `robots.txt` и `sitemap.xml` нельзя было
завести через админку: `page` требует запись в `pages`, `landing` рендерит через
`base.html.twig`, то есть целый HTML-документ, а любой другой тип уходит в
динамический список и отдаёт 404.

Запись в `navigation` для robots.txt:

| Поле | Значение |
|------|----------|
| `url` | `robots.txt` |
| `page_type` | `raw` |
| `template` | `robots` → `themes/<тема>/front/robots.html.twig` |
| `location` | `none` — чтобы файл не попал в меню |
| `page_config` | `{"content_type": "text/plain; charset=utf-8"}` |

Для `sitemap.xml` — то же самое с `content_type` = `application/xml; charset=utf-8`
и шаблоном `sitemap.xml.html.twig`. Наполнение sitemap (сбор ссылок) остаётся
за шаблоном: ядро только отдаёт файл.

Если шаблона в теме нет, используется `core/views/front/robots.html.twig`
(`User-agent: *` + `Disallow:`). Нет ни одного — 404.

Подробно: [Навигация и меню](../ru/content/navigaciya-i-menu.md).

## Исправлено

**`FOREIGN KEY constraint failed` при сохранении записи из админки.** Форма
отправляет пустую строку для незаполненного поля, а `create()` (в отличие от
`update()`) не приводил её к `NULL`. SQLite хранит `''` в INTEGER-колонке как
TEXT, поэтому пустой внешний ключ (`navigation.page_id`, `menu_items.page_id`,
`docs.section_id`, `sections.page_id`, `gallery.section_id`) не проходил
проверку ограничения — запись не сохранялась вовсе.

Тот же дефект тихо портил числовые поля без внешнего ключа: `menu_order` и
`parent_id` сохранялись как текст `''` вместо `0`.

Теперь пустые значения нормализуются в одном месте (`Database::normalizeEmptyValues()`):

- nullable не-текстовая колонка → `NULL`;
- NOT NULL числовая колонка → `0` (неотмеченный чекбокс больше не пишет текст);
- текстовые колонки не меняются — `''` там осмысленное значение.

Нормализация работает и в inline-редактировании ячейки.
