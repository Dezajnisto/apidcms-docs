# v2.1.5 — Notification badge count fix

**Date:** July 31, 2026
**Type:** bugfix

### Fixed
- **Notification count doubling:** when multiple active forms shared the same table (e.g. 3 forms → `contacts`), `BaseController::getUnreadNotificationsCount()` counted unread submissions 3 times. Now uses `SELECT DISTINCT source_table` — each table is counted once.

### Technical details
- Bug appeared on projects where multiple forms write to a shared source_table
- On `/admin/notifications` page the badge disappeared (NotificationsController passed its own correct `total_unread`), but returned on other pages
- Worsened by missing `form_name` filter in the count method (unlike `getFormStats()`)
