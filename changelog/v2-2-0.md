# v2.2.0 -- Настраиваемые лимиты контекста AI-помощника

**Дата:** 31 июля 2026
**Тип:** feature

## Что нового

- **Настраиваемые лимиты контекста AI** -- администратор может задать максимальный размер шаблонов и CSS, отправляемых в AI-помощник. Настройки: `ai_template_max_size` (байт на один .twig-файл), `ai_template_total_max` (суммарно на все шаблоны), `ai_css_max_size` (байт на custom.css).
- **По умолчанию 0** -- без ограничений. Актуально для DeepSeek с окном 1M токенов.
- **UI в настройках** -- секция «Размер контекста» во вкладке AI (Настройки → AI).

## Исправлено

- **`getCssContext()`** -- метод отсутствовал в коде (вызывался в `assistant()` и `generateTemplate()`, но не был реализован). CSS-контекст теперь корректно передаётся AI-помощнику.

## Изменённые файлы

- `core/init_system_tables.php` -- 3 новые настройки
- `core/src/Admin/AIController.php` -- `getCssContext()`, чтение лимитов из настроек
- `core/views/admin/settings/index.html.twig` -- UI секция лимитов
- `core/lang/ru.json` -- 9 новых ключей перевода
