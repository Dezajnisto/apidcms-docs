# v2.2.4 — PD consent log moved out of the core

**Date:** November 10, 2026
**Type:** fix

## Fixed

**`FormRenderer::logPdConsent()` wrote its log inside the core** —
`core/src/Admin/storage/logs/pd_consent.log`. The core copy inside a project is
overwritten by the rollout tool (`sync-core`) and is not tracked by git, so the
consent log existed on exactly one site out of five and would have vanished on
the first core update.

The log now goes to the project's `storage/logs/pd_consent.log` — next to the
other data that belongs to the project rather than to the code. The path comes
from `STORAGE_PATH`, so non-standard layouts work too.

## Upgrade notes

If a site already has `core/src/Admin/storage/logs/pd_consent.log`, move its
contents into `storage/logs/pd_consent.log` and remove the `storage` directory
inside `core/`. The core itself leaves such files alone (the rollout does not
delete data inside `core/`), but it does not move them either.

## Changed files

- `core/src/Core/FormRenderer.php` — log path
- `core/VERSION`
