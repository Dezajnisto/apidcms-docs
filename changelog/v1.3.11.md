## Дерево и поиск для связей

Две новые опции в `relations`:

### `tree: true` — иерархия

Если связанная таблица имеет колонку `parent_id`, опции строятся рекурсивным деревом с отступами `mdash;`:

```json
"relations": {
  "category_id": {
    "table": "categories",
    "label": "name",
    "value": "id",
    "tree": true
  }
}
```

Результат: подкатегории отображаются с отступом относительно родителей.

### `search: true` — поиск по списку

Вместо нативного `<select>` рендерится кастомный combobox с полем ввода:

```json
"relations": {
  "category_id": {
    "table": "categories",
    "label": "name",
    "value": "id",
    "search": true
  }
}
```

- Печатаете — список фильтруется
- Клик — значение выбрано
- `search` и `tree` можно комбинировать
