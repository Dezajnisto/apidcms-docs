# v2.1.0 — AI Ассистент во всех редакторах

**Дата:** 30 июля 2026
**Тип:** feature
**Теги:** ai,admin,ui,templates,forms,css

## Что нового

AI-ассистент (DeepSeek) теперь доступен во всех редакторах админ-панели, где пользователь пишет код или текст:

### Новые кнопки AI

- **CSS-редактор** (`/admin/design/css`) — генерация и редактирование CSS с учётом HTML-структуры шаблонов
- **Шаблоны плагинов** (`/admin/plugins/{name}/templates/{file}`) — генерация Twig-кода
- **Шаблоны форм** (`/admin/forms/{name}/templates/{file}`) — генерация Twig-кода
- **Системные промты** (настройки → AI) — AI помогает писать промты для самого себя (8 полей)
- **Фронтенд-промты** (настройки → AI Фронтенд) — AI-помощь для `ai_frontend_prompt` и `ai_frontend_personality`

### Контекст AI расширен

- **custom.css** теперь передаётся в контекст при генерации шаблонов — AI использует реальные CSS-классы проекта, а не выдуманные
- **Twig-шаблоны** передаются в контекст при генерации CSS — AI видит HTML-структуру и пишет стили под неё
- **Шаблоны** передаются в контекст при генерации новых шаблонов — AI соблюдает единый стиль

### Исправления

- **useTemplate()** теперь синхронизирует результат с CodeMirror (кнопка «Вставить в редактор» работала только с textarea)

### Технические детали

- Новый эндпоинт: `POST /admin/ai/generate-css`
- Новый метод: `Core\AI::generateCSS()`
- Новый метод: `AIController::getCssContext()`
- Новый метод: `AIController::getTemplatesContext()`
- Новый режим в `ai.js`: `mode:'css'`, `mode:'prompt'`
- Новая настройка: `ai_prompt_css` (системный промт для генерации CSS)
