# v2.0.0 — Architecture Restructuring

**Date:** July 30, 2026
**Type:** breaking change

Complete architecture restructuring following industry standards.

## Architecture

- `core_lib/` renamed to `core/`
- PHP classes: `core/src/{Core,Admin,Front}/` (PSR-4 style)
- `Admin\Core` namespace merged into `Admin`
- Views separated from code: `core/views/{admin,front}/`
- Static assets: `core/assets/{css,js}/` (was `static/`)
- `init.php` split into `bootstrap.php` + `router.php`
- Single entry point `www/index.php`

## Configuration & Data

- Configs: `config/{admin,front}.php` (was in `admin/config/` and `front/config/`)
- Runtime data: `storage/{database,uploads,cache}/`
- Storage proxy: PHP proxy for `/storage/uploads/*`, no symlinks
- Database not accessible via web (403)

## Themes

- `themes/{theme}/front/` and `themes/{theme}/admin/`
- New constants: `THEMES_PATH`, `CORE_VIEWS_ADMIN`, `CORE_VIEWS_FRONT`

## Removed

- `www/admin/` and `www/front/` — legacy directories
- `www/static` → `www/assets`
- Separate `admin/index.php` — everything through `www/index.php`

## Nginx

Added `nginx.conf.example` — ready-to-use configuration.

## Migration

All existing projects must be migrated. Migration script and full plan: `apidcms/MIGRATION-v2.md`.
