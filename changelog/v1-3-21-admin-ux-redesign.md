Панель администрирования получила новый дашборд вместо списка таблиц. Таблицы вынесены на отдельную страницу. Меню перегруппировано: Таблицы, CSS-стили, Формы — всё на своих местах. Иконки починены.

Панель администрирования apidcms получила редизайн: новый дашборд, перегруппированное меню, вынесенные на отдельную страницу таблицы.

## ✨ Новое

- **Дашборд:** приветственная страница с быстрыми ссылками вместо списка таблиц
- **Страница Таблиц:** /admin/tables — все таблицы БД с группировкой (системные/плагины/пользовательские)
- **Меню:** Главная → Таблицы → Шаблоны → CSS-стили → Файлы → Формы → Уведомления
- **Удалён** выпадающий список таблиц в сайдбаре
- **Файловый менеджер:** кнопка перенесена в header (синяя), иконка fa-folder-open

## 🚀 Улучшено

- **Оптимизация:** убран запрос всех таблиц БД при каждом рендере (больше не нужен для выпадающего меню)
- **Отступы** дашборда: 50px padding на центральной карточке
- **Разделители** в меню расставлены логичнее

## 🐛 Исправлено

- **Иконка Форм** починена: fa-wpforms (Pro-only) заменена на fa-file-lines (Free)
- **Редирект** после удаления таблицы: / → /tables
