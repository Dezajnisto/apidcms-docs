# v2.2.1 — External page pagination

**Date:** July 31, 2026
**Type:** fix

### Fixed
- **External page pagination:** `handleExternalPage()` list mode ignored the `items_per_page` parameter from `page_config`. All records were returned on a single page regardless of the setting. Now data is correctly sliced via `array_slice()`, and `current_page`, `total_pages`, `total_count` are passed to the template.

### How it works
- `items_per_page` in `page_config` (default 10)
- URL parameter: `?page=N`
- Changelog page on apidcms.dezajno.ru now shows 10 releases per page
