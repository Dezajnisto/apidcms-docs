Кнопка «Помощь» в хедере админки открывает боковую панель с документацией по текущей странице. Содержание, рендер Markdown, горячие клавиши.

## ✨ Новое

Контекстная справка в админке:
- Кнопка «Помощь» в хедере (рядом с Файлы)
- Панель справа (1/3 экрана), Esc или клик по оверлею — закрыть
- Авто-определение текущего роута → нужная статья из GitHub
- Содержание — быстрый доступ ко всей документации
- Рендер Markdown: таблицы, код, списки, заголовки

## 🚀 Улучшено

- Манифест кэшируется в localStorage на 24 часа
- Горячая клавиша ? для открытия (работала до убирания)
- Документация в репо apidcms-docs: 36 статей, 24 роута админки
