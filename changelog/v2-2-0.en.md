# v2.2.0 -- Configurable AI Context Limits

**Date:** July 31, 2026
**Type:** feature

## What's New

- **Configurable AI context limits** -- administrator can set maximum size for templates and CSS sent to the AI assistant. Settings: `ai_template_max_size` (bytes per .twig file), `ai_template_total_max` (total for all templates), `ai_css_max_size` (bytes for custom.css).
- **Default 0** -- unlimited. Relevant for DeepSeek with 1M token window.
- **Settings UI** -- "Context Size" section in the AI tab (Settings → AI).

## Bug Fixes

- **`getCssContext()`** -- method was missing from the code (called in `assistant()` and `generateTemplate()` but never implemented). CSS context is now properly sent to the AI assistant.

## Changed Files

- `core/init_system_tables.php` -- 3 new settings
- `core/src/Admin/AIController.php` -- `getCssContext()`, configurable limits
- `core/views/admin/settings/index.html.twig` -- context limits UI section
- `core/lang/ru.json` -- 9 new translation keys
