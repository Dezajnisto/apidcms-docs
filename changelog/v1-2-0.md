Универсальный тип dynamic заменил blog/catalog. Раздел документации /docs с Markdown-страницами. Полностью новый лендинг apidcms.dezajno.ru с Google Fonts и современным дизайном.

Мы переработали систему маршрутизации: универсальный тип dynamic заменил жёстко прописанные blog и catalog. Теперь любая таблица в БД может иметь собственные URL-адреса для каждой записи. Вместе с этим запущен раздел документации /docs и полностью обновлён лендинг apidcms.

## ✨ Новое

- Универсальный тип страниц dynamic — замена blog и catalog.
- Раздел документации /docs с Markdown-страницами и боковой навигацией.
- Новый дизайн лендинга: hero, comparison, AI-табы, архитектурная схема, CTA.
- Страница /changelog с таймлайном релизов и детальными страницами.
- Каталог плагинов /plugins с фильтрами и карточками.

## 🚀 Улучшено

- FrontController: удалены избыточные case 'blog' и case 'catalog' из switch.
- showDynamicItem теперь передаёт items в шаблон — можно строить боковую навигацию.
- ORDER BY с авто-фолбэком: если нет sort_order, используется id.

## 🐛 Исправлено

- Исправлено: проекты dezajno.ru и apidcms.dezajno.ru имели устаревшие копии FrontController.php (1962 строки вместо 1345).
- Исправлено: таблица navigation не имела колонки template на трёх проектах.
- Исправлено: CSS-стили документации требовали ручного сброса кэша (добавлен автобамп custom_css_version).
