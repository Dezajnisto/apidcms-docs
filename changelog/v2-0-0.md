# v2.0.0 — Реструктуризация архитектуры

**Дата:** 30 июля 2026
**Тип:** breaking change

Полная реструктуризация архитектуры CMS по «взрослому» стандарту.

## Архитектура

- `core_lib/` переименован в `core/`
- PHP-классы: `core/src/{Core,Admin,Front}/` (PSR-4 стиль)
- Namespace `Admin\Core` слит с `Admin`
- Шаблоны отделены от кода: `core/views/{admin,front}/`
- Статика: `core/assets/{css,js}/` (было `static/`)
- `init.php` разделён на `bootstrap.php` + `router.php`
- Единая точка входа `www/index.php`

## Конфигурация и данные

- Конфиги: `config/{admin,front}.php` (было в `admin/config/` и `front/config/`)
- БД и runtime: `storage/{database,uploads,cache}/`
- Storage proxy: PHP-прокси для `/storage/uploads/*`, симлинки не используются
- БД недоступна через веб (403)

## Темы

- `themes/{theme}/front/` и `themes/{theme}/admin/`
- Новые константы: `THEMES_PATH`, `CORE_VIEWS_ADMIN`, `CORE_VIEWS_FRONT`

## Удалено

- `www/admin/` и `www/front/` — рудименты
- `www/static` → `www/assets`
- Отдельные `admin/index.php` — всё через `www/index.php`

## Nginx

Добавлен `nginx.conf.example` — готовая конфигурация.

## Миграция

Все существующие проекты должны быть мигрированы. Скрипт миграции и полный план: `apidcms/MIGRATION-v2.md`.
