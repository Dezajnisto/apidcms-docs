# v2.1.0 — AI Assistant in All Editors

**Date:** July 30, 2026
**Type:** feature
**Tags:** ai,admin,ui,templates,forms,css

## What's New

The AI Assistant (DeepSeek) is now available in all admin panel editors where users write code or text:

### New AI Buttons

- **CSS Editor** (`/admin/design/css`) — generate and edit CSS with awareness of template HTML structure
- **Plugin Templates** (`/admin/plugins/{name}/templates/{file}`) — generate Twig code
- **Form Templates** (`/admin/forms/{name}/templates/{file}`) — generate Twig code
- **System Prompts** (Settings → AI) — AI helps write prompts for itself (8 fields)
- **Frontend Prompts** (Settings → AI Frontend) — AI assistance for `ai_frontend_prompt` and `ai_frontend_personality`

### AI Context Expanded

- **custom.css** is now passed as context during template generation — AI uses real project CSS classes instead of made-up ones
- **Twig templates** are passed as context during CSS generation — AI sees HTML structure and writes matching styles
- **Templates** are passed as context during new template generation — AI maintains consistent style

### Fixes

- **useTemplate()** now syncs results with CodeMirror (the "Insert into editor" button only worked with textarea before)

### Technical Details

- New endpoint: `POST /admin/ai/generate-css`
- New method: `Core\AI::generateCSS()`
- New method: `AIController::getCssContext()`
- New method: `AIController::getTemplatesContext()`
- New modes in `ai.js`: `mode:'css'`, `mode:'prompt'`
- New setting: `ai_prompt_css` (system prompt for CSS generation)
