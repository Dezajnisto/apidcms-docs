# v2.0.1 — Hotfix: Plugin Stability & v2 Compatibility

**Date:** July 30, 2026
**Type:** hotfix

Critical bugs in the plugin system discovered during project migration to v2.

### Fixes

- **PluginManager:** `db.migrate` no longer crashes when called without a database (null-guard). Previously, `loadPlugins()` from `bootstrap.php` triggered migrations before DB initialization.
- **PluginManager:** plugins no longer loaded twice. Added `$loadedPlugins` array — `init.php` executes only on the first call.
- **FrontController:** added public `getDatabase()` method for plugins to access the DB instance.
- **VisitStats:** fixed `$db->changes()` call replaced with `$db->exec()` (the `changes()` method was missing from Database).

### Plugins (v2 Compatibility)

- **Account 1.0.1:** removed broken migration line.
- **Subscription 1.4.1:** `getDb()` now uses `$fc->getDatabase()` with v2 config path fallback.
- **Favorites 1.0.1:** fixed config paths in `init.php` and controller.
- **Credits 1.0.1:** fixed config path.

### Files Affected

- `core/src/Core/PluginManager.php`
- `core/src/Front/FrontController.php`
- `core/src/Core/VisitStats.php`
