# v2.1.1 — Stats Page Improvements

**Date:** July 30, 2026
**Type:** feature

## What's New

The visit statistics page (`/admin/stats`) received several UI and data retention improvements.

### New Filter Periods

The period switcher now shows: 1d / 7d / 14d / 30d (was 7 / 30 / 60 / 90). This provides a more detailed view for shorter time ranges.

### Retention: 30 Days by Default

- Default stats retention reduced from 90 to 30 days — data older than 30 days is automatically deleted
- Settings dropdown (`/admin/settings`) updated: available values 7, 14, 30, 60, 90 days
- Cleanup fallback in code also changed to 30 days

### Peak Hours: Labels Under Every Bar

The hourly activity chart now shows an hour label under every bar (0, 1, 2, ... 23). Previously labels were only shown under every third hour (0, 3, 6...), making the bars look uneven.

### Changed Files

- `core/src/Admin/StatsController.php` — new periods `[1, 7, 14, 30]`
- `core/views/admin/stats/index.html.twig` — period switcher + peak hours
- `core/views/admin/settings/index.html.twig` — retention dropdown
- `core/init_system_tables.php` — default 30 days
- `core/src/Front/FrontController.php` — cleanup fallback 30 days
