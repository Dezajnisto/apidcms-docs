## external: авто-генерация content_url и авторизация в fetchContent

### Что нового

- Авто-генерация content_url из item.id — для API с единой базой URL (Buildin.ai, Notion, NocoDB). Если элемент имеет поле id, а content_url отсутствует — apidcms автоматически создает URL для загрузки контента.
- Single-item external страницы с Markdown-контентом — дочерние страницы теперь могут загружать и рендерить Markdown. Переменная detail_content доступна в _single.html.twig.
- Authorization header в fetchContent() — при загрузке контента через content_url теперь передается заголовок Authorization из page_config.

### Пример

Интеграция wearefun.ru с Buildin.ai — свадебный гид из 11+ страниц: https://wearefun.ru/svadba. Страницы загружаются через search API, контент рендерится через |markdown_to_html.

### Технические детали

- core_lib/front/app/controllers/FrontController.php — авто content_url в handleExternalPage
- core_lib/core/ExternalPageLoader.php — Authorization header в fetchContent()
