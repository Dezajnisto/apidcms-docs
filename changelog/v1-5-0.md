# v1.5.0 — Полная интернационализация админки

**Выпуск:** 29 Июля 2026
**Тип:** feature

## Что нового

- **1200 ключей в языковых пакетах** (`ru.json` + `en.json`) — полный перевод всех 31 шаблона админки
- **Переведены все шаблоны:** таблицы (просмотр/форма/структура/колонка/CSV), формы (список/редактор/шаблоны), плагины, уведомления, файловый менеджер, настройки, статистика, кэш, дизайн, документация
- **Переведены все контроллеры:** `SettingsController`, `NotificationsController`, `PluginAdminController`, `FormsController`, `FileManagerController` — флеш-сообщения, заголовки, ошибки
- **JS-строки через `__t()`** — `window.__lang` в `base.html.twig` + `__t()` хелпер для JavaScript
- **Файловый менеджер:** все JS-уведомления, алерты, промпты, подсказки переведены
- **Документация:** статья «Интернационализация» (RU + EN) с инструкциями по добавлению новых языков

## Ключевая конвенция

- **Канонический язык — английский.** Ключи на английском (`sidebar.home`, `common.save`)
- **Русский всегда полный.** Каждый ключ в `en.json` обязан иметь запись в `ru.json`
- **Fallback на русский.** Если ключ отсутствует в выбранной локали, Lang возвращает русский перевод

## Структура i18n

```
core_lib/admin/
├── lang/
│   ├── ru.json        ← 1200 ключей (обязательный, fallback)
│   └── en.json        ← 1200 ключей (канонические имена ключей)
├── app/
│   ├── core/Lang.php  ← Cинглтон, загрузка JSON, t(key, params)
│   ├── controllers/
│   │   └── BaseController.php  ← initLang(), lang_all, lang() в Twig
│   └── views/          ← {{ lang('key') }} во всех 31 шаблонах
```

## Как добавить новый язык

1. Создать `core_lib/admin/lang/{code}.json` (например `de.json`)
2. Заполнить переводы (можно копировать `en.json` и перевести значения)
3. Добавить `<option value="de">Deutsch</option>` в `settings/index.html.twig`
4. `sync-core all` + сбросить OPcache и Twig-кэш

## Технические детали

- **`Lang::t(key, params)`** — параметры через `{name}` плейсхолдеры
- **`{{ lang('key') }}`** в Twig — двойные скобки обязательны (одинарные `{ }` — буквальный текст)
- **`$this->lang->t('key')`** в PHP-контроллерах (не `Lang::t()` — `__callStatic` не работает в PHP 8)
- **`__t('key')`** в JavaScript через `window.__lang`
- **`lang_all`** — Twig-глобал, все 1200 ключей доступны в JS
- **`admin_language`** — системная настройка в `system_settings`, значение по умолчанию `ru`
