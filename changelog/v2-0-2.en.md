# v2.0.2 — Bulk Delete in Admin Table Viewer

**Date:** July 30, 2026
**Type:** feature

Added checkbox column and bulk actions bar to the admin table viewer.

**What's new:**
- **Bulk delete:** select multiple records via checkboxes and delete with one click
- **Select-all checkbox** in the table header (current page only)
- **Sticky bulk actions bar** at the bottom: selected count, deselect button, delete button
- **Confirmation dialog** showing the number of records to delete
- **Auto-cleanup** of entity\_relations for deleted records
- **Smart banners:** success (with count), FK error, empty selection
- **Safety:** checkbox column does not render for tables without an `id` column
- **Pagination preserved** after bulk deletion

**Changed files:**
- `core/src/Admin/TableController.php` — new `bulkDelete()` method
- `core/src/Admin/App.php` — route `POST /table/{table}/bulk-delete`
- `core/views/admin/table/view.html.twig` — checkboxes, bulk bar, JS
- `core/lang/ru.json` — 7 new translation keys
