# v2.2.1 — Пагинация для внешних страниц

**Дата:** 31 июля 2026
**Тип:** fix

### Исправлено
- **Пагинация на внешних страницах:** метод `handleExternalPage()` в list-режиме не учитывал параметр `items_per_page` из `page_config`. Все записи отдавались одной страницей, независимо от настройки. Теперь данные корректно нарезаются через `array_slice()`, в шаблон передаются `current_page`, `total_pages`, `total_count`.

### Как это работает
- Параметр `items_per_page` в `page_config` (по умолчанию 10)
- Параметр URL: `?page=N`
- Страница changelog на apidcms.dezajno.ru теперь показывает по 10 релизов на странице
