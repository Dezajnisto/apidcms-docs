### Исправление сохранения checkbox в настройках плагинов

**Проблема 1 — checkbox всегда true:**
При снятии галки браузер не отправляет поле в POST. Старый код проверял `isset()` — поле отсутствовало, значение не обновлялось, оставалось `true`.

**Решение:**
Для `type: checkbox` теперь: нет поля в POST → `false`. Для остальных типов поведение без изменений.

**Проблема 2 — plugin.json засорялся runtime-полями:**
`handleSaveSettings()` сохранял весь объект плагина (включая `path`, добавленный PluginManager), а не только оригинальные поля plugin.json.

**Решение:**
При сохранении собирается чистый массив только с полями `name`, `version`, `description`, `enabled`, `dependencies`, `settings`.
