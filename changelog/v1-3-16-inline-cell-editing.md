Двойной клик по ячейке таблицы открывает модальное окно с EasyMDE Markdown-редактором. Тулбар, превью, горячие клавиши — всё на месте.

## ✨ Новое

<ul><li>EasyMDE Markdown-редактор в модальном окне (всегда активен)</li><li>Тулбар: bold, italic, heading, quote, списки, ссылки, изображения</li><li>Превью: side-by-side и fullscreen режимы</li><li>Горячие клавиши Ctrl+Enter (сохранить) и Escape (отменить)</li><li>Визуальная обратная связь: зелёная вспышка при успехе, красная при ошибке</li></ul>

## 🚀 Улучшено

<ul><li>Вертикальные разделители ячеек для лучшей читаемости</li><li>Подсветка отдельной ячейки при наведении (курсор cell)</li><li>Оригинальные стили EasyMDE</li></ul>

## 🐛 Исправлено

<ul><li>Валидация имени колонки через структуру таблицы (защита от SQL-инъекций)</li><li>JSON API с корректными HTTP-заголовками</li></ul>
