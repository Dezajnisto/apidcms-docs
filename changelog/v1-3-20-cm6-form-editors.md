TEXT-поля на странице редактирования записи таблицы теперь используют CodeMirror 6 с автоматическим определением языка. JSON-конфиги форматируются в pretty-print, Markdown и HTML подсвечиваются.

Форма редактирования записей таблиц получила интеллектуальные редакторы кода для всех текстовых полей.

## ✨ Новое

- **Авто-детект языка:** поля `_config` → JSON, `{`/`[` → JSON, `#` → Markdown, HTML-теги → HTML
- **JSON pretty-print:** содержимое автоматически форматируется с отступами при открытии
- **Тёмная тема** oneDark на всю высоту редактора
- Четыре режима: JSON, Markdown, HTML (Twig), CSS

## 🚀 Улучшено

- Все возможности CodeMirror 6: номера строк, поиск, bracket matching, история
- Тёмный фон заполняет весь редактор (не только строки с текстом)

## 🐛 Исправлено

- Исправлен обрыв тёмного фона при коротком содержимом (min-height через тему)
