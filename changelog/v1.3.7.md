### Авто-инкремент views_count

В метод `showDynamicItem()` добавлен автоматический инкремент колонки `views_count`. Если колонка есть — `+1`, обёрнуто в try/catch.

### _GET в шаблонах фронтенда

GET-параметры доступны в любом Twig-шаблоне через `_GET`: `{% if _GET.category == 'text' %} active{% endif %}`.

### get_filters — серверные фильтры через GET

`page_config.get_filters` мапит GET-параметры на WHERE: `?category=text&tool=GPT` → SQL WHERE.

### sort_options — серверная сортировка через GET

`page_config.sort_options` позволяет переключать сортировку: `?sort=popular`. Валидация имени колонки через структуру таблицы.

### json_decode Twig-фильтр

Добавлен фильтр `|json_decode` для разбора JSON-строк в шаблонах: `{% set features = plan.features|json_decode %}`.

### Авто-поддерживаемые колонки dynamic-страниц

| Колонка | Назначение |
|---------|-------------|
| `slug` | URL-идентификатор |
| `status` | Фильтрация активных |
| `sort_order` | Сортировка и prev/next |
| `created_at` | Резервная сортировка |
| `views_count` | Авто-инкремент при просмотре |
