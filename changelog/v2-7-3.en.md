# v2.7.3 — the showcase moved to its own domain, apidcms.ru

**Date:** 23 November 2026
**Type:** patch

## What changed

The documentation and the plugin catalog now live at **https://apidcms.ru** —
the CMS got a domain of its own instead of a subdomain of another zone. The old
address `apidcms.dezajno.ru` answers with a permanent redirect (301), so links in
bookmarks, articles and emails keep working.

**In the core** exactly one link changed: the "All documents" button of the admin
context help panel (`views/admin/_help_panel.html.twig`) points to the new
domain. Nothing else behaves differently — the update is safe for every site
running the CMS, nothing needs to be reconfigured.

If your templates or articles still point to the old address, you do not have to
change them: the redirect stays. For new links, prefer `apidcms.ru`.

## How to update

```bash
git pull
```

and redeploy the core to your site (or copy `www/core/` from the fresh version).
