<h3>Контекстная справка в панели администрирования</h3>
<p>В хедере админки появилась кнопка <strong>«Помощь»</strong>. При клике открывается боковая панель с документацией, соответствующей текущей странице.</p>

<h4>Как работает</h4>
<ul>
<li>Система определяет текущий URL админки и находит нужную статью в манифесте документации</li>
<li>Статья загружается с GitHub (raw markdown) и рендерится в HTML</li>
<li>Поддерживаются таблицы, блоки кода, списки, заголовки, ссылки</li>
<li>Манифест кэшируется в localStorage браузера на 24 часа</li>
</ul>

<h4>Содержание</h4>
<p>Ссылка «Содержание» в шапке панели открывает полный список всех статей документации, сгруппированных по разделам. Клик по любой статье загружает её в панель — быстрый доступ ко всей документации из любого места админки.</p>

<h4>Роуты</h4>
<p>24 роута админки замапплены на статьи документации. Если для страницы нет отдельной статьи — открывается содержание.</p>
