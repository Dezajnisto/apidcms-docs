# v2.0.1 — Hotfix: стабильность плагинов и v2-совместимость

**Дата:** 30 июля 2026
**Тип:** hotfix

Исправлены критические баги в системе плагинов, обнаруженные при миграции проектов на v2.

### Исправления

- **PluginManager:** `db.migrate` больше не падает при вызове без базы данных (null-guard). Ранее `loadPlugins()` из `bootstrap.php` вызывал миграции до инициализации БД.
- **PluginManager:** плагины больше не загружаются дважды. Добавлен массив `$loadedPlugins` — `init.php` выполняется только при первом вызове.
- **FrontController:** добавлен публичный метод `getDatabase()` для доступа плагинов к экземпляру БД.
- **VisitStats:** исправлен вызов `$db->changes()` на `$db->exec()` (метод `changes()` отсутствовал в Database).

### Плагины (совместимость с v2)

- **Account 1.0.1:** удалена битая строка миграции.
- **Subscription 1.4.1:** `getDb()` использует `$fc->getDatabase()` с fallback на v2-путь к конфигу.
- **Favorites 1.0.1:** исправлены пути к конфигу в `init.php` и контроллере.
- **Credits 1.0.1:** исправлен путь к конфигу.

### Затронутые файлы

- `core/src/Core/PluginManager.php`
- `core/src/Front/FrontController.php`
- `core/src/Core/VisitStats.php`
