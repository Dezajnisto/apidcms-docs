# v2.1.2 — Language persistence on navigation

**Date:** July 30, 2026
**Type:** hotfix

## Fixed

- **Language persistence on navigation.** The `site_lang` cookie is no longer cleared when navigating links without a language prefix. The system now checks the cookie and uses the stored language preference.
- **Changelog links.** Release links now use `url()` and automatically get the language prefix (`/en/changelog/v2-1-1` instead of `/changelog/v2-1-1`).
- **Explicit base language switch.** The RU switcher adds `?lang=ru` to explicitly signal a language reset to the base language.

### Changed files

- `core/src/Front/FrontController.php` — `detectLocale()`: cookie is checked on bare URLs, no longer deleted; `?lang=ru` for explicit reset
- `themes/default/front/base.html.twig` — RU switcher: `href="/{{ current_path }}?lang=ru"`
- `themes/default/front/changelog.html.twig` — links via `{{ url(...) }}` instead of hardcoded paths
