## sort.then — вторичная сортировка dynamic-списков

В `page_config` для dynamic-страниц ключ `sort` теперь поддерживает опциональный `then` — массив вторичных полей сортировки.

### Было (одна колонка)
```json
"sort": {"field": "created_at", "order": "DESC"}
```

### Стало (с вторичной сортировкой)
```json
"sort": {
  "field": "category",
  "order": "ASC",
  "then": [
    {"field": "sort_order", "order": "ASC"},
    {"field": "created_at", "order": "DESC"}
  ]
}
```

### Как работает
1. Основная сортировка по `sort.field` + `sort.order`
2. Если указан `sort.then` — поля добавляются в ORDER BY через запятую
3. Имена полей фильтруются `[a-zA-Z_]` и оборачиваются в двойные кавычки
4. Если `then` отсутствует — поведение как раньше (полная обратная совместимость)

### Что изменилось в коде
- `FrontController::showDynamicList` — строка `$orderBy` собирается как цепочка `"field1" ASC, "field2" DESC, ...`
