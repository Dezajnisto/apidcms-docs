<h3>Inline-редактирование ячеек с EasyMDE</h3>
<p>Двойной клик по ячейке в таблице — и открывается модальное окно с полноценным Markdown-редактором. Больше не нужно уходить на отдельную форму, чтобы поправить контент.</p>

<h4>EasyMDE — всегда активен</h4>
<ul>
<li>Тулбар: bold, italic, heading, quote, списки, ссылки, изображения</li>
<li>Превью: side-by-side и fullscreen</li>
<li>Горячие клавиши: Ctrl+Enter — сохранить, Escape — отменить</li>
<li>Сохранение через AJAX, ячейка мигает зелёным при успехе</li>
</ul>

<h4>Дизайн</h4>
<ul>
<li>Оригинальные стили EasyMDE с CodeMirror-подсветкой</li>
<li>Вертикальные разделители между ячейками</li>
<li>Подсветка конкретной ячейки при наведении (курсор cell)</li>
</ul>

<h4>Безопасность</h4>
<ul>
<li>API-эндпоинт доступен только через админку (ADMIN_ACCESS)</li>
<li>Имя колонки валидируется через структуру таблицы</li>
<li>Подготовленные запросы через PDO</li>
</ul>
