Таблицы на главной странице админки теперь группируются по происхождению: системные (pages, forms, navigation...), таблицы плагинов (account, cart, subscription) и пользовательские. Все метки переведены на русский язык, колонки выровнены по ширине между группами.

Главная страница админки стала удобнее: таблицы сгруппированы по категориям.

## ✨ Новое

- Таблицы на дашборде разделены на три группы: **Системные**, **Плагины**, **Пользовательские**
- Плагины объявляют свои таблицы через поле `tables` в `plugin.json`
- Все метки и заголовки переведены на русский язык

## 🚀 Улучшено

- Фиксированная ширина колонок для визуального выравнивания между группами
- Подзаголовки групп с пояснениями

```
// plugin.json — секция tables
{
  "name": "account",
  "tables": ["users", "user_tokens"]
}
```
