# v2.2.2 — items_per_page=0 disables pagination for external pages

**Date:** July 31, 2026
**Type:** hotfix

## Fixed

- **External page pagination:** v2.2.1 introduced pagination with a default of 10 items per page. This broke the documentation sidebar — it showed only the first 10 articles.
- **items_per_page: 0** — now disables pagination and shows all items on one page. Applied to the `/docs` page on apidcms.dezajno.ru.
- Default value (10) for other pages remains unchanged — backward compatible.

## Other

- Removed `www.backup-before-migration` from the repository (473 files, 65K lines)
- README.md translated to two languages (EN+RU)

## Changed files

- `core/src/Front/FrontController.php` — items_per_page=0 support in handleExternalPage()
