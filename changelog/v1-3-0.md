Скрипт установки одной командой, параллельные чтение/запись SQLite, защита от рекурсии при обновлении ядра.

Этот релиз делает apidcms по-настоящему автономным: один скрипт — и проект готов к работе. Попутно решена критическая проблема с блокировками БД на shared-хостинге.

## ✨ Новое

### install.php — автоустановка

Скрипт `php install.php` разворачивает проект одной командой:
- Проверка PHP 8.1+ и всех расширений (sqlite3, curl, mbstring, json, gd, openssl, fileinfo, zip, xml, session)
- Создание структуры папок (storage, uploads, logs, database)
- Генерация конфигов (admin/config.php, front/config.php)
- Установка Composer-зависимостей
- Инициализация БД с системными таблицами
- Защита: обновление ядра не разносит install.php на рабочие проекты

### WAL-режим SQLite

Конкурентный доступ к БД (веб + CLI) вызывал крах FastCGI на всём аккаунте хостинга:
- `journal_mode=WAL` — параллельные чтение и запись
- `busy_timeout=5000` — ожидание до 5 секунд вместо мгновенной ошибки
- CLI-обновления больше не могут уронить сайт
