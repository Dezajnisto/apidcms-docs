10+ багфиксов по результатам трёх раундов тестирования установки с нуля. Восстановление core_lib на всех проектах.

Три раунда тестирования «с нуля» на реальных доменах — и десяток найденных багов исправлен. Плюс аварийное восстановление после реструктуризации репозитория.

## 🐛 Исправлено

### Установщик — 8 исправлений

- **403 на /admin:** install.php теперь создаёт .htaccess и admin/index.php
- **Session warnings:** явный session_save_path в init.php
- **API-ключ:** шаг ввода ключа убран (настраивается позже в админке)
- **Seed-данные:** 6 страниц + 3 блог-поста при установке
- **front/config:** автоматически создаётся папка с config.php
- **core_lib/front/config/config.php:** разморожен из .gitignore (fallback-конфиг)
- **base.html.twig:** padding на main для отступов
- **Template fallback:** проект → core_lib через prependPath

### Восстановление core_lib

- обновление ядра на старой версии удалило core_lib/ на всех 5 проектах
- Восстановлено, обновление ядра починено (7 правок путей)
- Авто-синхронизация views для проектов без своего front/app/

### CSS и шаблоны

- admin.css восстановлен (потеря spacing-классов после перекомпиляции)
- Cache-шаблон восстановлен после случайного удаления
- .gitignore исправлен: admin/app/views/cache/ — исходники, не runtime-кэш

### Совместимость

- PHP 8.1: scandir вместо SplFileInfo::getSubPathName()
- Скелетон устарел — install.php делает всё
