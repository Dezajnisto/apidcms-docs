### Поиск по сайту (page_type search)

Новый тип страницы `search` добавляет полнотекстовый поиск по всему контенту CMS.

**Как работает:**
- Автоматически собирает все таблицы из активных записей `navigation` (source_table)
- Плюс всегда ищет в таблице `pages`
- Авто-определяет текстовые колонки через PRAGMA table_info
- LIKE-поиск с релевантностью: точное совпадение в заголовке > начало слова > вхождение

**Результаты:**
- Подсветка найденного `<mark>`
- Сниппет 150-200 символов вокруг совпадения
- Сортировка по релевантности
- Дедупликация по URL

**Подключение:**
- Создать запись в `navigation` с `page_type='search'`, `url='search'`
- Шаблон `search.html.twig` — в ядре, проект может переопределить
- Нет записи в навигации = поиск не работает

**Методы:**
- `handleSearch()` — основной обработчик
- `buildSearchSnippet()` — формирование сниппета
- `calculateSearchRelevance()` — подсчёт релевантности
