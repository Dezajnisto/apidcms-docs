# v1.3.25 — Интеграция документации в AI-ассистент и панель справки

**Дата:** 2026-07-28

## DocsFetcher — документация из GitHub

- Новый класс `Core\DocsFetcher` — загружает документацию из GitHub-репозитория `Dezajnisto/apidcms-docs`
- Кэширование: манифест 1 час, отдельные статьи 6 часов
- Метод `getKnowledgeBase()` — собирает все статьи как текст для AI-контекста
- AI-ассистент теперь знает документацию apidcms и использует её для ответов

## Панель справки в админке

- Кнопка **«?»** в шапке админки открывает контекстную справку
- Автоматически показывает статьи, релевантные текущей странице админки
- Оглавление (TOC), корректный рендеринг таблиц, адаптивная ширина
- CSS перенесён в `<head>` для предотвращения FOUC
- `showToc()` вынесен в глобальную область видимости

**Файлы:** DocsFetcher.php (новый), AI.php, AIController.php, base.html.twig, _help_panel.html.twig
