# v1.3.25 — Интеграция документации в AI-ассистент

**Дата:** 2026-07-28

## Новый класс: DocsFetcher

- `Core\DocsFetcher` — загружает документацию apidcms из GitHub-репозитория `Dezajnisto/apidcms-docs`
- Кэширование: манифест 1 час, отдельные статьи 6 часов
- Кэш-директория: `admin/storage/docs_cache/` (создаётся автоматически)
- Метод `getKnowledgeBase()` — собирает все 36 статей как текст для AI-контекста (~131 КБ)
- `stripFrontmatter()` — автоматически убирает YAML-шапку перед отправкой в AI
- Graceful fallback: если GitHub недоступен — AI работает без документации
- `invalidateCache()` — сброс всего кэша

## AI-ассистент: документация в системном промпте

- `AI::assistant()` — новый контекст `docs` добавляется в системный промпт
- AI теперь знает что он в apidcms и использует документацию как источник знаний
- Может отвечать на вопросы о настройке, плагинах, шаблонах, формах, таблицах

## AIController: автоматическая загрузка

- Перед каждым запросом к AI: `DocsFetcher::getKnowledgeBase()` → контекст
- Обработка ошибок: если загрузка не удалась — AI работает только с БД-контекстом

## Файлы

- `core_lib/core/DocsFetcher.php` (новый)
- `core_lib/core/AI.php` (assistant() обновлён)
- `core_lib/admin/app/controllers/AIController.php` (assistant() обновлён)
