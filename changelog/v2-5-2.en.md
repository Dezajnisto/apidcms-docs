# v2.5.2 — the assistant no longer passes internals off as data, and spend is visible

**Date:** November 16, 2026
**Type:** fix

## Why

MCP and the tools-based assistant were tested against a mock model: it dutifully
called a tool and returned the result. The first run against a real model on live
sites exposed three things the mock hid.

## What was wrong

1. **Internals of third-party tools looked like site data.** Asked "which tables
   does this site have", the assistant honestly listed `_litestream_lock` and
   `_litestream_seq` — SQLite replication bookkeeping created by Litestream. The
   core knew about `sqlite_*`, `system_*` and `plugin_*`, but not about tables
   whose name starts with an underscore.
2. **The legacy assistant mode dumped everything into the prompt.** With
   `ai_assistant_tools=0` the model received `users`, `user_tokens`,
   `system_settings` and `plugin_*` — internals presented as site data.
3. **The legacy mode did not answer at all.** `DocsFetcher` printed
   "Array to string conversion" on localised manifest titles right into the
   response body: the JSON broke and the chat showed garbage instead of an answer.
   The bug had been there ever since manifest titles became `{"ru","en"}` objects.

## What changed

- a leading `_` in a table name marks it internal, same as `sqlite_`;
- the table dump in the legacy mode is filtered by the same
  `SchemaInspector::isSystemTable()`;
- section and article titles go through `localeValue()`.

## New: you can see what a question costs

`POST /admin/ai/assistant` now returns `steps` and `usage`
(`prompt_tokens`, `completion_tokens`, `total_tokens`, summed over all steps).
Without it neither the cost nor the claim "tools are cheaper than a dump" can be
checked.

Measured on a site with 36 documentation articles:

| Question | Mode | Steps | Prompt tokens |
|---|---|---|---|
| "the largest table?" | tools | 2 | 6 034 |
| "how do I enable caching?" | tools | 3 | 5 905 |
| any question | legacy dump | 1 | ~54 000 |

## Compatibility

No breaking changes. The assistant response gained two fields; the old ones stay.
