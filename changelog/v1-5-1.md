# v1.5.1 — Фикс локализации (фронтенд + хелп-панель)

## Фронтенд

- **Фронтенд всегда русский:** `resolveLocale` больше не использует `admin_language`. Локаль жёстко `ru` до появления отдельной настройки `site_language`.
- **Array to string conversion** на `/docs` и `/changelog` исправлен: `ExternalPageLoader::resolveLocaleValue()` + `resolveLocale()` раскрывают i18n-объекты `{"ru":"...","en":"..."}` из manifest.json.

## Админка

- **Хелп-панель:** Contents теперь на языке админки. JS-функция `resolveI18n(value, lang)` раскрывает i18n-заголовки.
- `admin_lang` передаётся как Twig global из `BaseAdminController`.
- Cache key манифеста бампнут v2→v3.

## Инфраструктура

- Исправлена структура `core_lib/` после коррапта: vendor, дубликаты `cms.db`, отсутствующие файлы восстановлены.

### Файлы

| Файл | Изменение |
|------|-----------|
| `core/ExternalPageLoader.php` | +resolveLocaleValue(), +resolveLocale() |
| `front/app/controllers/FrontController.php` | locale `ru` вместо `admin_language` |
| `admin/app/core/BaseAdminController.php` | +`admin_lang` Twig global |
| `admin/app/views/_help_panel.html.twig` | +resolveI18n(), cache key v2→v3 |
