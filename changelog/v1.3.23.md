<h3>Документация из GitHub</h3>
<p>Страницы документации на apidcms.dezajno.ru теперь загружаются из отдельного GitHub-репозитория <a href="https://github.com/Dezajnisto/apidcms-docs">apidcms-docs</a> через external-тип страниц.</p>

<h4>Как это работает</h4>
<ul>
<li>Список статей: manifest.json → 36 документов с метаданными (title, slug, section, content_url)</li>
<li>Отдельная статья: raw markdown с GitHub → рендерится фильтром markdown_to_html</li>
<li>Кэширование: 1 час (TTL), сброс через админку → Очистить кэш</li>
</ul>

<h4>strip_frontmatter</h4>
<p>Новая опция в page_config для external-страниц. Убирает YAML front-matter (---...---) из загружаемого Markdown, чтобы метаданные не попадали в контент страницы.</p>
<pre><code>{
  "source_url": ".../manifest.json",
  "json_path": "docs",
  "strip_frontmatter": true
}</code></pre>
