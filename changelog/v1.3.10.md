## Выпадающие списки для связанных полей

При редактировании записи в dynamic-таблице поля, ссылающиеся на другие таблицы (например `category_id`), теперь отображаются как удобный `<select>` со значениями из связанной таблицы — вместо необходимости вручную вводить ID.

### Настройка

В `page_config` динамической страницы добавьте секцию `relations`:

```json
{
  "relations": {
    "category_id": {
      "table": "categories",
      "label": "name",
      "value": "id"
    }
  }
}
```

- **table** — таблица, из которой брать значения
- **label** — колонка для отображения в списке
- **value** — колонка для значения (обычно `id`)

Обратная совместимость: страницы без `relations` работают как раньше.
