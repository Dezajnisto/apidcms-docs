# v2.0.2 — Массовое удаление записей в админке

**Дата:** 30 июля 2026
**Тип:** feature

Добавлена колонка с чекбоксами и панель массовых действий в просмотр таблиц админки.

**Новое:**
- **Массовое удаление:** выбор нескольких записей через чекбоксы и удаление одной кнопкой «Удалить выбранные»
- **Чекбокс «Выбрать всё»** в заголовке таблицы (в пределах текущей страницы)
- **Липкая панель действий** внизу таблицы: счётчик выбранных записей, кнопки «Снять выбор» и «Удалить выбранные»
- **Подтверждение** перед удалением с указанием количества записей
- **Автоочистка связей** entity\_relations для удаляемых записей
- **Умные баннеры:** успех (сколько удалено), FK-ошибка, пустой выбор
- **Безопасность:** колонка чекбоксов не рендерится для таблиц без колонки `id`
- **Сохранение пагинации** после массового удаления

**Изменённые файлы:**
- `core/src/Admin/TableController.php` — новый метод `bulkDelete()`
- `core/src/Admin/App.php` — роут `POST /table/{table}/bulk-delete`
- `core/views/admin/table/view.html.twig` — чекбоксы, панель действий, JS
- `core/lang/ru.json` — 7 новых ключей перевода
