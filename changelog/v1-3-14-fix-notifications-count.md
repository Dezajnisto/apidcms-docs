Бейдж с количеством непрочитанных заявок теперь учитывает все формы из таблицы forms, а не только страницы типа form в навигации.

Красный бейдж с количеством непрочитанных заявок теперь правильно считает все формы.

## ✨ Новое

Запрос в getUnreadNotificationsCount() изменён: вместо поиска форм через navigation, теперь используется прямая выборка из таблицы forms.

## 🚀 Улучшено

Бейдж в сайдбаре теперь показывает реальное количество непрочитанных заявок для всех форм.

## 🐛 Исправлено

Формы, добавленные только в таблицу forms (без страницы в навигации), ранее не учитывались в счётчике.
