### IN-фильтры в get_filters

Поле get_filters теперь поддерживает значения через запятую: `?category_id=1,2,3` → `WHERE category_id IN (1,2,3)`. Одиночные значения работают как раньше (`= ?`). Обратная совместимость полная.

### Дерево категорий в dynamic-шаблонах

В dynamic-страницы (source_table + page_config) автоматически передаются переменные:
- `categories_tree` — иерархическое дерево из таблицы categories
- `active_category_ids` — массив активных ID из `?category_id=`
- `open_category_ids` — цепочка родительских ID для раскрытия аккордеона

Если таблицы `categories` нет — try/catch, переменные пустые. На существующие шаблоны не влияет.
