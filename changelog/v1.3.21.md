<h3>Новый дашборд админки</h3>
<p>Главная страница /admin/ больше не показывает список таблиц. Вместо этого — приветственный дашборд с быстрыми ссылками на ключевые разделы: Таблицы, Шаблоны, Файлы, Формы.</p>

<h4>Отдельная страница Таблиц</h4>
<p>Список всех таблиц базы данных теперь на странице /admin/tables — системные, плагинов и пользовательские, сгруппированы по категориям.</p>

<h4>Меню перегруппировано</h4>
<p>Новый порядок в сайдбаре: Главная → Таблицы → Шаблоны → CSS-стили → Файлы → Формы → Уведомления → Плагины → Статистика → Кэш → Настройки.</p>
<p>Выпадающий список таблиц в меню удалён — теперь это обычная ссылка на страницу Таблиц.</p>

<h4>Файловый менеджер в верхней панели</h4>
<p>Кнопка открытия файлового менеджера перенесена из сайдбара в header, рядом с кнопкой «Просмотр сайта». Синяя кнопка с иконкой папки.</p>
