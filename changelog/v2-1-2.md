# v2.1.2 — Сохранение языка при навигации

**Дата:** 30 июля 2026
**Тип:** hotfix

## Исправлено

- **Сохранение языка при навигации.** Кука `site_lang` больше не сбрасывается при переходе по ссылкам без языкового префикса. Теперь система проверяет куку и использует сохранённый язык.
- **Ссылки в чейнджлоге.** Ссылки на релизы используют `url()` и автоматически получают языковой префикс (`/en/changelog/v2-1-1` вместо `/changelog/v2-1-1`).
- **Явный сброс на базовый язык.** Переключатель RU добавляет `?lang=ru` для явного сигнала сброса языка.

### Изменённые файлы

- `core/src/Front/FrontController.php` — `detectLocale()`: кука проверяется при голом URL, не удаляется; `?lang=ru` для явного сброса
- `themes/default/front/base.html.twig` — RU-переключатель: `href="/{{ current_path }}?lang=ru"`
- `themes/default/front/changelog.html.twig` — ссылки через `{{ url(...) }}` вместо жёстких путей
