<h3>entity_relations — обязательная таблица</h3>
<p>Упрощение структуры БД: <code>entity_relations</code> переведена в разряд обязательных таблиц, неиспользуемые таблицы удалены из установщика.</p>

<h4>Что изменилось</h4>
<ul>
<li><strong>Обязательные таблицы (5):</strong> pages, forms, navigation, system_settings, entity_relations</li>
<li><strong>Удалены из установщика:</strong> sections, gallery, reviews, menus, menu_items — эти таблицы не использовались ядром и при необходимости создаются пользователем вручную</li>
<li><strong>Миграция entity_relations:</strong> отдельный миграционный блок удалён — таблица теперь создаётся вместе с обязательными</li>
<li><strong>visit_stats:</strong> остаётся опциональной, создаётся при включении статистики</li>
</ul>

<h4>Почему</h4>
<ul>
<li><code>entity_relations</code> уже используется админкой (TableController) и фронтендом (FrontController) — без неё ломаются M:M-связи и фильтрация</li>
<li>Таблицы sections, gallery, reviews, menus, menu_items были заготовками, которые ни разу не использовались в реальных проектах</li>
</ul>

<h4>Обновлённая документация</h4>
<p>Страница «Обзор таблиц» обновлена — теперь отражает актуальный состав системных таблиц.</p>
