# v1.4.0 — i18n панели администрирования

**Выпуск:** 28 Июля 2026
**Тип:** feature

## Что нового

- **Языковые пакеты** в `core_lib/admin/lang/`: `ru.json` (80+ ключей) и `en.json` (полный перевод сайдбара и хедера)
- **Класс `Admin\Core\Lang`** — минимальный синглтон: загружает JSON-пакет, fallback на русский для отсутствующих ключей
- **Twig-функция `{{ lang('key') }}`** доступна во всех шаблонах админки
- **Сайдбар и хедер** (`base.html.twig`) переведены на `lang()` — 19 замен
- **Системная настройка `admin_language`** (`ru` по умолчанию) — добавляется автоматически через `init_system_tables.php`
- **Выбор языка** в Настройках → вкладка Основные: выпадашка Русский/English, сохраняется как обычная настройка

## Как это работает

```
system_settings.admin_language = "ru"
         ↓
Lang::getInstance() → admin/lang/ru.json
         ↓
{{ lang('sidebar.home') }} → "Главная"
         ↓
Если ключа нет в текущем языке → fallback на ru.json
```

## Как добавить новый язык

1. Создать `core_lib/admin/lang/{code}.json` (например `de.json`)
2. Добавить ключи — только те, что отличаются от русского
3. Добавить `<option>` в `settings/index.html.twig`
4. `sync-core all`

## Технические детали

- `Lang::getInstance($locale)` — синглтон, инициализируется в `BaseController::initLang()`
- Локаль читается из `system_settings.admin_language` через БД
- При отсутствии настройки — `ru` по умолчанию
- `Lang::reload($locale)` — для принудительной смены языка без перезагрузки страницы (на будущее)
- Все контроллеры используют `BaseController` (не `BaseAdminController`)
