Страница просмотра записи объединена со страницей редактирования: кнопки удаления/копирования, горячие клавиши, информационный блок и сообщения об успехе теперь на одной странице.

## ✨ Новое

Объединение страниц просмотра и редактирования:
- Кнопки Удалить, Копировать, Создать новую на странице редактирования
- Инфо-блок с таблицей и ID (кликабельный для копирования)
- Горячие клавиши: Ctrl+S сохранить, Ctrl+← назад к таблице
- Редирект после create/update сразу на форму редактирования
- Убран дублирующий глазик из списка записей

## 🚀 Улучшено

- На 217 строк меньше кода (удалены метод viewItem, роут и шаблон view_item)
- Один клик вместо двух: создал запись → сразу на форме редактирования
- Все действия с записью собраны в одном месте

```
// Было: два шаблона, два роута
/admin/table/pages/id/2     → view_item.html.twig (только просмотр)
/admin/table/pages/edit/2   → form.html.twig (только редактирование)

// Стало: один шаблон, один роут
/admin/table/pages/edit/2   → form.html.twig (просмотр + редактирование + действия)
```
