# apidcms-docs — правила работы

Документация apidcms на двух языках (RU + EN), changelog и `manifest.json`,
по которому сайт продукта собирает разделы документации.

Публичный репозиторий: текст читают пользователи CMS.

## Структура

```
ru/, en/            по папке на язык, внутри — по разделу:
  quickstart/       быстрый старт
  content/          контент, страницы, таблицы
  forms/            формы
  templates/        шаблоны и темы
  settings/         настройки
  ai/               AI-ассистент
  plugins-dev/      разработка плагинов
  features/         обзор возможностей
changelog/          записи changelog (RU + EN)
manifest.json       индекс: slug, title, section, order, content_url
README.md
```

## Правила

- **Два языка — один коммит.** Добавил или изменил статью в `ru/` — сделай то же
  в `en/`. Статья без пары в манифесте не появится в меню.
- **Новый файл статьи = запись в `manifest.json`**: `slug`, `title` (ru/en),
  `section`, `section_title`, `order`, `description`, `content_url`. Путь в
  `content_url` должен **точно** совпадать с именем файла (опечатка = 404 в
  документации).
- **Раздел должен существовать в `m['sections']`** — иначе группа в боковом меню
  выводится без заголовка.
- **Версии в changelog** — единый формат `vX.Y.Z`. Версия в `manifest.json`
  (`version`) соответствует последней записи changelog.
- **Пишем для пользователя CMS, а не для разработчика ядра**: шаги в интерфейсе,
  скриншоты, что произойдёт; без внутренних путей и имён наших установок.
- **Не обещать несуществующего.** Если фичи нет в текущей версии — её нет и в
  документации.
- Правки ядра в этом репозитории не делаются — здесь только текст и манифест.
