# SEO — мета-теги и советник

Плагин закрывает техническую часть SEO: то, что поисковые системы требуют
формально, и то, что чаще всего забывают на живых сайтах.

Раздел находится в админке: **SEO** в левом меню (`/admin/seo`).

## Что плагин делает сам

После установки и включения на сайте появляются:

| Что | Где видно |
|---|---|
| `title`, `description`, `robots`, `canonical` | `<head>` каждой страницы |
| Open Graph и Twitter Card | превью ссылки в мессенджерах и соцсетях |
| JSON-LD (`WebSite`, `BreadcrumbList`, `Article`) | микроразметка для поисковиков |
| `hreflang` | если в настройках сайта включены дополнительные языки |
| `/sitemap.xml` | карта сайта: страницы, разделы и записи |
| `/robots.txt` | отдаётся, только если своей страницы robots.txt нет |

Плагин не требует правок в шаблонах: он вставляет теги в готовый HTML.
Если тема выводит `title` и `description` сама, дубли удаляются — в `<head>`
остаётся один набор тегов.

## Настройка

**Плагины → SEO → Настройки.** Значения хранятся в базе сайта, а не в файле плагина.

| Настройка | Что значит |
|---|---|
| Выводить мета-теги | главный выключатель. Снимите — плагин перестанет трогать `<head>` |
| Open Graph и Twitter | блок для соцсетей |
| JSON-LD | микроразметка |
| Картинка для соцсетей по умолчанию | используется, когда у страницы нет своей |
| Шаблон заголовка | например `{title} — Мой сайт`; пусто — заголовок выводится как есть |
| Отдавать sitemap.xml | карта сайта |
| robots.txt | «авто» (по умолчанию), «всегда» или «не трогать» |
| noindex для 404 | страница ошибки не попадает в индекс |
| Кнопка «Сгенерировать» | доступ к нейросети через ключ DeepSeek из настроек AI |

## Обзор сайта

Раздел **SEO** открывается списком всех страниц сайта с оценкой от 0 до 100:

- **средняя оценка** — по проверенным страницам;
- **страницы в обходе** — сколько всего адресов видят поисковики;
- **требуют работы** — оценка ниже 60;
- фильтры «Все / Требуют работы / Не проверены / Хорошо» и поиск по адресу,
  заголовку и ключевой фразе.

Кнопка **«Проверить сайт»** пересчитывает оценки всех страниц. Проверка идёт
порциями по 25–100 страниц, поэтому каталог из тысяч записей не подвешивает
сервер. Проверка офлайновая: плагин читает базу сайта, в интернет не ходит.

## Редактор страницы

Открывается кликом по странице в обзоре. Здесь:

- **SEO-заголовок** и **описание** — с счётчиками длины и подсказкой, какое
  значение работает, если поле пустое;
- **ключевая фраза** — по ней проверяются заголовок, описание, текст, адрес и плотность;
- **robots** — `index`/`noindex`, для служебных страниц;
- **канонический адрес** — если страница открывается по нескольким адресам;
- **Open Graph** — отдельные значения для соцсетей, если нужны другие, чем в выдаче;
- **чек-лист** с оценкой и пояснением к каждому пункту;
- **превью сниппета** — как страница будет выглядеть в поиске;
- **«Сгенерировать заголовок и описание»** — нейросеть напишет черновик по тексту страницы.

Пустое поле значит «работает значение из контента»: заголовок страницы,
её описание и картинка. Кнопка **«Сбросить к контенту»** возвращает страницу
к этому состоянию.

## Что проверяет чек-лист

| Группа | Пункты |
|---|---|
| Заголовок | есть; 30–65 символов; не повторяется на других страницах |
| Описание | есть; 70–170 символов; не повторяется |
| Текст | от 300 слов; один H1; подзаголовки H2–H4 |
| Ключевая фраза | выбрана; в заголовке, описании, тексте и адресе; плотность 0,4–4,5% |
| Картинки и ссылки | alt у картинок; внутренние ссылки |
| Адрес | латиница и дефисы; не глубже трёх уровней |
| Соцсети и индексация | картинка для соцсетей; noindex; канонический адрес |

Проверки, которые к странице не применимы (объём текста у страницы-списка,
ссылки внутри карточки товара), в оценку не входят. Поэтому пустая страница
не получает 0 только за то, что к ней неприменимо.

Оценка — ориентир, а не приговор: 90 не гарантирует позиций, но 40 почти
всегда означает потерю трафика.

## Карта сайта и robots.txt

`sitemap.xml` собирается автоматически из:

- страниц (`pages`), у которых статус «активен»;
- разделов навигации;
- записей таблиц, выводимых через разделы.

В карту не попадают: страницы с `noindex`, записи с неактивным статусом,
разделы поиска и AI-чата. Карта кэшируется на час, кнопка «Пересобрать
sitemap» в обзоре сбрасывает кэш сразу.

Важно: если на сайте уже есть своя страница `sitemap.xml` или `robots.txt`
в навигации (тип `raw`), плагин их **не перекрывает** — ваша версия остаётся
главной. Это защита от ситуации, когда правки в robots.txt молча исчезают.

## Редиректы

**SEO → Редиректы.** Постоянный (301) редирект нужен, когда страница переехала:
старый адрес продолжает собирать ссылки и трафик, но ведёт на новый.

- редирект работает для точного адреса, без учёта `?параметров`;
- 301 отдаётся до рендера страницы, поэтому работает и для удалённого контента;
- счётчик срабатываний показывает, ходят ли по старому адресу.

Обратный случай — старый адрес всё ещё существует в контенте: тогда откроется
страница, а редирект не сработает. Сначала удалите или переименуйте страницу.

## Журнал 404

**SEO → Ошибки 404.** Список адресов, которых нет на сайте, с числом обращений
и последней датой. Для каждого адреса плагин предлагает похожий существующий —
это подсказка, а не готовое решение: проверьте глазами.

Технические адреса (стили, картинки, `/admin`, `/api`) в журнал не попадают.
Записи не удаляются автоматически — чистите вручную кнопкой.

## Нейросеть

Генерация работает через ключ DeepSeek из **Настроек → AI** — тот же, что у
встроенного ассистента. Внешних ключей заводить не нужно.

В редакторе страницы сверху есть панель **«Заполнить нейросетью»** с четырьмя
кнопками:

| Кнопка | Что вернёт |
|---|---|
| **Всё сразу** | заголовок, описание и ключевую фразу за один запрос |
| **Заголовок** | только SEO-заголовок, 30–65 символов |
| **Описание** | только description, 120–165 символов |
| **Ключевые фразы** | три варианта на выбор, от общего к точному |

Такие же кнопки-«искры» есть рядом с полями заголовка, описания и ключевой
фразы — не нужно искать генерацию в другом месте.

Счётчики длины рядом с полями показывают то, что реально уйдёт на сайт: если поле пустое, там
не «0 символов», а серым «49 (из контента)» — длина значения, которое берётся из текста страницы.

**Результат не подставляется сам.** Он показывается как предложение под полем
с кнопками «Применить» и «Отменить»: видно, что именно напишется, и старая
версия не теряется молча. Для фраз варианты приходят кнопками — выбираете кликом.

Что уходит в модель: текст страницы (первые 4000 символов), её заголовок,
адрес и ключевая фраза, если она уже введена. Отдельные промты на каждое поле
дают более точный ответ и тратят меньше токенов, чем «всё сразу».

Оценка считается не моделью, а чек-листом — поэтому она не меняется от
настроения нейросети. После применения предложений нажмите «Сохранить»: оценка
пересчитывается при сохранении.

Нет ключа — панель генерации недоступна, всё остальное работает.

## Если тема управляет тегами сама

По умолчанию плагин правит готовый HTML. Если нужно, чтобы тема выводила
теги сама, вызовите в её `<head>`:

```twig
<head>
    {{ seo_meta() }}
</head>
```

Тогда плагин второй раз ничего не вставит. Ещё есть `seo_sitemap_url()` —
абсолютный адрес карты сайта, если тема строит свой индекс.

## Ограничения

- Плагин не проверяет скорость сайта, ссылочную массу и поведенческие факторы.
- Модель пишет текст по содержанию страницы: если текста нет, качество будет
  соответствующим.
- Карта сайта ограничена 3000 записей на таблицу — для очень больших каталогов
  нужен отдельный генератор.
- Плагин не меняет схему ядра: SEO-поля лежат в своих таблицах
  (`plugin_seo_meta`, `plugin_seo_redirect`, `plugin_seo_404`).
