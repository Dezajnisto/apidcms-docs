# ⚙️ Настройки сайта

Страница **Настройки** позволяет управлять параметрами сайта прямо из админки, без редактирования файлов.

**Где находится:** боковое меню → шестерёнка «Настройки»
**URL:** `/admin/settings`

---

## 🗂️ Система вкладок

Настройки разделены на 5 вкладок для удобной навигации:

| Вкладка | Содержание |
|---------|-----------|
| **Основные** | Название, описание, email, favicon |
| **AI** | API-ключ, модель, системные промты |
| **AI Фронтенд** | Настройки публичного AI-чата и безопасность |
| **Статистика** | Включение сбора и срок хранения |
| **Системные** | Email, кэширование и служебные параметры |

Переключение между вкладками — без перезагрузки страницы. Активная вкладка сохраняется в URL (hash).

---

## 📋 Вкладка «Основные»

Простые настройки: название сайта, описание, контактный email и т.д.

**Как редактировать:**
1. Нажмите в поле «Значение» напротив нужной настройки
2. Измените текст
3. Нажмите синюю кнопку 💾 (сохранить)

**Как добавить новую:**
1. Нажмите «+ Добавить настройку»
2. Введите ключ (например, `site_email`)
3. Введите значение
4. Нажмите «Добавить»

**Как удалить:** нажмите красную корзину 🗑 напротив настройки.

---

## 🤖 Вкладка «AI»

Настройки AI-ассистента. Подробно описаны в разделе [🤖 AI Ассистент](ai-assistant.md).

Здесь можно:
- Вставить или сменить **API ключ** DeepSeek
- Выбрать модель
- Отредактировать **системные промты** для каждого режима

---

## 🌐 Вкладка «AI Фронтенд»

Настройки AI для публичной части сайта и безопасность доступа к данным. Подробнее — в разделе [AI Ассистент → Безопасность](ai-assistant.md).

- Раздельные или общие настройки AI
- Белый список таблиц (`ai_public_tables`)
- Лимит строк для контекста (`ai_sample_limit`)

---

## 📊 Вкладка «Статистика»

Управление встроенной аналитикой. Подробнее — в разделе [Статистика посещений](stats.md).

- Включение/выключение сбора
- Срок хранения данных (30–365 дней)

---

## 🔧 Вкладка «Системные»

Продвинутые настройки: email-уведомления и служебные параметры.

| Ключ | Назначение |
|------|-----------|
| `email_driver` | Способ отправки email (api/smtp) |
| `email_api_provider` | Провайдер email API |
| `email_api_key` | Ключ API для email |
| `email_api_endpoint` | URL эндпоинта email API |
| `email_smtp_host` | SMTP сервер |
| `email_smtp_port` | SMTP порт (587) |
| `email_smtp_username` | SMTP пользователь |
| `email_smtp_password` | SMTP пароль |
| `email_smtp_encryption` | SMTP шифрование (tls) |
| `email_from_email` | Email отправителя |
| `email_from_name` | Имя отправителя |
| `custom_css_version` | Версия CSS (для сброса кэша браузера) |
| `cache_enabled` | Включение Twig-кэша |
