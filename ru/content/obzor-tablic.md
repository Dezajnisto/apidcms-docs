# 🗄️ Обзор таблиц

## Что такое таблица?

Таблица — это структура для хранения однотипных данных. Проще говоря, это как **электронная таблица Excel**, только в базе данных.

Каждая строка — это одна запись.  
Каждая колонка — это одно поле (например, заголовок, текст, изображение).

**Пример:** таблица «Контакты»

| id | name | email | message |
|----|------|-------|---------|
| 1 | Иван | ivan@mail.ru | Хочу заказать сайт |
| 2 | Анна | anna@ya.ru | Вопрос по услугам |

## Системные таблицы (обязательные)

При установке CMS автоматически создаются 5 системных таблиц:

| Таблица | Для чего |
|---------|----------|
| **pages** | Страницы сайта (главная, блог, контакты и др.) |
| **forms** | Формы обратной связи и заявок |
| **navigation** | Навигация и типы страниц (page, blog, dynamic, ai и др.) |
| **system_settings** | Все настройки сайта (название, AI, email и т.д.) |
| **entity_relations** | Связи между таблицами (M:M — многие-ко-многим) |

Плюс опционально: **visit_stats** — создаётся автоматически при включении статистики посещений в настройках.

## Пользовательские таблицы

Вы можете **создавать свои таблицы** для любых данных:
- Каталог товаров
- Портфолио работ
- Отзывы клиентов
- Категории и теги
- Всё, что угодно

**Как это работает:**
1. Создаёте таблицу с нужными полями
2. Добавляете записи через админку
3. Настраиваете отображение через раздел «Навигация»
4. Пишете (или выбираете готовый) шаблон

> 💡 **Совет:** Новая таблица = новый тип данных на вашем сайте.  
> Создаёте «товары» — появляется каталог. Создаёте «отзывы» — появляется раздел отзывов.
