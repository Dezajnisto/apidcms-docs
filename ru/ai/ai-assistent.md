# 🤖 AI Ассистент

В CMS встроен AI-ассистент на базе DeepSeek. Он помогает создавать шаблоны, проектировать таблицы, заполнять контент и отвечать на вопросы.

---

## 🎯 Как вызвать

**Способ 1 — Плавающая кнопка**
В правом нижнем углу экрана круглая фиолетовая кнопка со звездой ✨ — нажмите её.

**Способ 2 — Контекстная кнопка**
В разделах, где AI может помочь, есть специальные кнопки:
- Редактор шаблонов — кнопка «AI»
- Создание таблицы — кнопка «AI — Создать таблицу»
- Просмотр таблицы — кнопка «AI — Сгенерировать контент»
- Создание записи — кнопка «AI — Заполнить поля»

---

## 📝 Режимы работы

### 1. Универсальный ассистент (плавающая кнопка)
Просто задайте вопрос:
- *«Как сделать слайдер в Twig?»*
- *«Какие таблицы есть в БД?»*
- *«Напиши SQL запрос для выборки последних 5 постов»*

### 2. Генерация шаблонов (кнопка в редакторе)
AI получает контекст: какие таблицы и поля есть в БД.
Пишите:
- *«Сделай карточки товаров из таблицы products: фото, название, цена, кнопка "Купить"»*
- *«Добавь блок с формой обратной связи под текстом страницы»*
- *«Переделай список в сетку по 3 колонки»*

После генерации нажмите **«📋 Вставить в редактор»**.

### 3. Создание таблицы (кнопка на странице создания)
Опишите словами, какие данные хотите хранить:
- *«Таблица для каталога товаров: название, описание, цена, фото, категория»*
- *«Таблица для отзывов клиентов: имя, город, оценка от 1 до 5, текст отзыва, дата»*
- *«Таблица для акций: заголовок, описание, скидка в процентах, дата начала, дата окончания»*

AI вернёт JSON-структуру. Нажмите **«📋 Применить структуру»**.

### 4. Генерация контента (кнопка на странице таблицы)
Заполните таблицу данными:
- *«Сгенерируй 10 постов для блога о веб-разработке»*
- *«Сделай 5 отзывов клиентов с разными оценками»*
- *«Добавь 3 товара из категории "Дизайн интерьера"»*

После генерации нажмите **«💾 Вставить N записей»**.

### 5. Заполнение формы (кнопка на создании записи)
AI видит все поля формы и подбирает значения:
- *«Создай страницу "О нас" с описанием компании»*
- *«Добавь контакт: имя Иван, email ivan@mail.ru, телефон +7 999 123-45-67»*
- *«Сделай 3 новости на тему технологий»*

После генерации нажмите **«📋 Заполнить форму»**.

## 🧹 Управление чатом

- **«🗑 Очистить»** — сбросить диалог и начать заново
- **Автоочистка** — при смене контекста (шаблон → таблица) чат очищается автоматически
- Закрыть модалку — крестик ✕ или клик вне окна

## ⚙️ Настройки AI

Управляются в разделе **Настройки → AI (DeepSeek)** (вкладка «AI»):

| Параметр | Описание |
|----------|----------|
| `ai_api_key` | 🔑 Ключ API DeepSeek |
| `ai_model` | Модель (по умолч. deepseek-chat) |
| `ai_prompt_template` | Системный промт для генерации шаблонов |
| `ai_prompt_table` | Промт для структуры таблиц |
| `ai_prompt_content` | Промт для генерации контента |
| `ai_prompt_fill_form` | Промт для заполнения форм |
| `ai_prompt_assistant` | Промт для общего ассистента |

Промты можно менять — настраивайте поведение AI под свои задачи.

### AI Фронтенд (вкладка «AI Фронтенд»)

Отдельная вкладка для настройки AI на публичной части сайта (чат с посетителями):

| Параметр | Описание |
|----------|----------|
| `ai_frontend_use_system` | Использовать системные настройки AI или отдельные |
| `ai_frontend_api_key` | Отдельный API-ключ для фронтенда |
| `ai_frontend_model` | Модель для публичного чата |
| `ai_frontend_prompt` | Системный промт для чата с посетителями |
| `ai_frontend_personality` | Персонаж/тон ответов (например «дружелюбный консультант») |

## 🔒 Безопасность AI-контекста

AI-ассистент **не видит** системные и приватные таблицы. По умолчанию заблокированы:

- `system_settings` — настройки сайта
- `users` — пользователи
- `user_tokens` — токены авторизации
- `sqlite_sequence` — служебная таблица SQLite

### Белый список таблиц

Администратор сам решает, к каким таблицам AI имеет доступ. Настройка `ai_public_tables` — JSON-массив разрешённых таблиц. Находится во вкладке **AI Фронтенд** в виде чек-листа.

По умолчанию **ни одна таблица не разрешена** (безопасность прежде всего).

### Лимит строк (`ai_sample_limit`)

Ограничивает количество строк, передаваемых AI в качестве контекста. По умолчанию **50 строк**. Значение `0` — передавать только структуру таблицы, без данных.

Настройка находится там же, во вкладке AI Фронтенд.

### Размер контекста (v2.2.0)

Настройки, ограничивающие объём шаблонов и CSS, отправляемых в AI-помощник. Находятся во вкладке **AI** (Настройки → AI → Размер контекста):

| Параметр | Описание | По умолчанию |
|----------|----------|:---:|
| `ai_template_max_size` | Макс. байт на один .twig-файл | 0 |
| `ai_template_total_max` | Суммарный лимит на все шаблоны | 0 |
| `ai_css_max_size` | Макс. байт на custom.css | 0 |

**0 = без ограничений.** Актуально для современных моделей (DeepSeek — 1M токенов). Если используете модель с маленьким контекстным окном — задайте лимиты.

## 📚 База знаний (с v1.3.25)

AI-ассистент имеет доступ к полной документации apidcms из репозитория `apidcms-docs`.

**Как это работает:**
- При каждом запросе AI получает текст всех 36 статей документации (~131 КБ)
- Документация кэшируется локально: манифест 1 час, статьи 6 часов
- YAML front-matter автоматически убирается перед отправкой в AI
- Если GitHub недоступен — AI работает без документации (fallback)

**Что это даёт:**
- AI может отвечать на вопросы о настройке, плагинах, шаблонах, формах
- Знает все возможности apidcms — не только то, что видит в БД
- Пример: *«Как создать форму с галочкой ПД и AJAX-отправкой?»* — AI объяснит по документации

Подробнее: [База знаний AI — документация apidcms](/docs/baza-znanij-ai-dokumentaciya)
